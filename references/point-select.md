# 点选型挑战：读提示 → 定位 → 坐标

> 适用：图中带提示（"请点击图中 XX"，常为彩色、倾斜、水印），需要在**同一张图内**点击目标图标/文字。
> 输出：相对图片宽高的百分比 `px/py` + 像素 `x/y` + 置信度；点击动作交给浏览器/GUI 控制。

## 1. 完整流水线

```text
挑战图
 ├─ A 读提示（instruction）
 │    彩色文字掩膜 → 膨胀合并/去噪（连通域）→ PCA 测角 → ±转正候选 → OCR
 │    → regex/同义词映射得到目标 key
 │    （提示由外部文本给出时跳过本阶段）
 ├─ B 定位（localization）
 │    目标颜色掩膜 → 连通域 + 邻近碎片聚合 → 归一化 S×S
 │    → 模板库旋转扫描取最大 IoU → 每个候选对每类的得分
 └─ C 选择（pick）
      按目标 key + 场景特殊规则选候选 → 坐标
      无候选达标 / 多候选无法区分 → ambiguous，列出候选，不猜
```

## 2. 阶段 A：读提示

- 颜色阈值按场景配置（见 scenario.json 的 `instruction.color`）。
  DRNH 黄色：`R>170, G>170, B<130, (R+G-2B)>60`。
- 形态学：膨胀 2 次让笔画成块 → 连通域去小碎片（<200 像素）。
- PCA 测角存在**符号歧义**，必须生成 ± 两个转正候选分别 OCR。
- OCR 默认 macOS Vision（`scripts/ocr_text`，中英繁简）；中文行易乱码时以英文行为准。
- 用 `targets[].regex`（忽略大小写）把提示文本映射到目标 key。

## 3. 阶段 B：定位候选

- 目标颜色掩膜（DRNH 绿色：`G>170 且 R<140 且 B<140`）。
- 连通域（minComponent，DRNH=800）→ 邻近碎片聚合（mergeDistance，DRNH=160），
  同一图标可能断裂成多个连通域。
- 每个候选裁剪后归一化到 64×64。
- 模板库：每类一个或多个模板；对每个候选在 0–360° 每 15° 旋转扫描，取最大 IoU。

## 4. 阶段 C：选择规则

- 默认：候选对目标类得分 `≥ threshold`（DRNH=0.6）即选中。
- 特殊规则 `nonTargetBelow`（DRNH earth）：选「所有非目标类得分均 < 阈值」的唯一候选
  （地球有不同视角，避免误配）。
- 经验值：诱饵对自身模板约 0.87–0.94；非目标通常 ≤ 0.43。
- 无候选达标或一次出现 2 个无法区分的候选 → 返回 ambiguous，按 scenario-guide 扩模板或请人工。

## 5. 坐标口径

- `px/py`：候选中心相对图片**宽/高**的百分比，整数 0–100。
- `x/y`：像素坐标。
- 调用方负责把"图片坐标"映射到页面元素：若挑战图按原尺寸显示可直接换算到视口；
  若被缩放/裁剪，需按实际渲染比例与元素偏移换算。

## 6. 顺序点选

部分挑战要求按提示**依次**点击多个目标（"依次点击 月、亮、…"）。对每个目标 key 重复 B/C，
各自输出坐标，按提示顺序返回；已点目标是否需要从图中掩膜剔除依站点而定。
